# হিসাব খাতা — ব্যক্তিগত লেনদেন ট্র্যাকার

একটি স্ট্যাটিক ওয়েবসাইট (HTML/CSS/JS, কোনো বিল্ড টুল লাগে না) যেটা **Google Sheet**-কে ডাটাবেস
হিসেবে ব্যবহার করে। GitHub Pages-এ ফ্রি হোস্ট করা যায়। সাইট খোলার সাথে সাথে **পাসওয়ার্ড লক
স্ক্রিন** দেখায় — সঠিক পাসওয়ার্ড ছাড়া কেউ ডেটা দেখতে বা লিখতে পারবে না, এবং পাসওয়ার্ডটা কখনো
পাবলিক গিটহাব কোডে থাকে না (নিচে ধাপ ৩ ও ৫ দেখুন)।

## এতে যা যা আছে

- **ড্যাশবোর্ড** — ক্যাশ ব্যালেন্স, ব্যাংক ব্যালেন্স, মোবাইল ব্যাংকিং ব্যালেন্স, বিনিয়োগের লাভ/ক্ষতি,
  সম্পদের মূল্য এবং আনুমানিক **যাকাত** এর হিসাব
- **আয়** ও **ব্যয়** — তারিখ, খাত, পরিমাণ, নোট
- **দেনাদার** (যারা আমার কাছ থেকে টাকা পাবে... মানে আমি যাদের টাকা দিয়েছি, তারা আমাকে ফেরত দেবে) —
  নাম, কারণ, ফেরত নেয়ার হিসাব সহ
- **পাওনাদার** (আমি যাদের কাছে টাকা পাব) — একই রকম ট্র্যাকিং
- **অন্যের আমানত** — অন্য কারো টাকা আপনার কাছে জমা রাখা, নাম অনুযায়ী (পৃষ্ঠার উপরে **কার কত টাকা আমার কাছে আছে** তালিকা); তিনি টাকা ফেরত নিলে কারণ,
  এবং আপনি সেই টাকা থেকে খরচ করলে তারও এন্ট্রি
- **ক্যাশ** লেনদেন (জমা/উত্তোলন)
- **ব্যাংক অ্যাকাউন্ট** (ব্যাংকের নাম + অ্যাকাউন্ট নাম্বার) ও প্রতিটি অ্যাকাউন্টের লেনদেন
- **মোবাইল ব্যাংকিং অ্যাকাউন্ট** (bKash/Nagad/...) ও জমা/উত্তোলন/ট্রান্সফার
- **বিনিয়োগ** — কোথায় বিনিয়োগ করেছেন, বিনিয়োগকৃত পরিমাণ ও বর্তমান মূল্য (লাভ/ক্ষতি অটো হিসাব)
- **লভ্যাংশ** — কোন বিনিয়োগ থেকে কত লভ্যাংশ পেলেন
- **সম্পদ** — কী কিনেছেন/বিক্রি করেছেন, ক্রয়মূল্য ও বর্তমান মূল্য; **অবচয় (depreciation)** হার দিলে
  কেনার তারিখ থেকে সময় ধরে মূল্য নিজে কমে যায় (সরলরৈখিক বা হ্রাসমান ব্যালেন্স পদ্ধতি)
- **মাসিক বাজেট** — বেতন এন্ট্রি করলে নির্ধারিত শতাংশে ক্যাটেগরিতে ভাগ হয় (ডিফল্ট: খাবার ৪০%, বাসা ভাড়া ২০%,
  ইউটিলিটি ৫%, চিকিৎসা ৫%, শিক্ষা ১০%, অন্যান্য ৫%, সঞ্চয় ১০%)। প্রতি ক্যাটেগরিতে কত বরাদ্দ, কত খরচ, কত বাকি বা
  কত বেশি খরচ — মাসভিত্তিক রেকর্ড থাকে। শতাংশ বদলালে আগের মাসের হিসাব অপরিবর্তিত থাকে
- **আয়কর** — চলতি করবছরের (১ জুলাই–৩০ জুন) আয় ও লভ্যাংশ থেকে করযোগ্য আয় ও আনুমানিক কর ড্যাশবোর্ডে দেখায়।
  করমুক্ত সীমা, স্ল্যাব ও হার সবই ওয়েবসাইট থেকে এডিট করা যায় ("আয়কর স্ল্যাব" ও "কর সেটিংস" ট্যাব)

সব ডেটা আপনার নিজের Google Sheet-এ জমা থাকে — কোনো তৃতীয় পক্ষের সার্ভার লাগে না।

## ধাপ ১: Google Sheet তৈরি করুন

1. [sheets.google.com](https://sheets.google.com) এ গিয়ে একটি নতুন ফাঁকা Spreadsheet তৈরি করুন।
   নাম দিন যেমন `হিসাব খাতা ডাটা`।
2. এর ভেতরে আলাদা করে কোনো ট্যাব/হেডার বানাতে হবে না — নিচের ধাপে Apps Script কোড প্রথমবার
   চালানোর সময় নিজে থেকেই সব শিট (Income, Expense, Debtors, ...) ও হেডার তৈরি করে নেবে।

## ধাপ ২: Apps Script যুক্ত করুন

1. শিটের ভেতরে উপরে **Extensions → Apps Script** এ ক্লিক করুন।
2. যে এডিটর খুলবে, সেখানে ডিফল্ট `Code.gs` ফাইলের সব কোড মুছে ফেলে এই রিপোর
   `apps-script/Code.gs` ফাইলের পুরো কোড পেস্ট করুন।
3. উপরে বাম পাশে প্রজেক্টের নাম দিন (যেমন `Hisab Khata API`) এবং সেভ করুন (Ctrl/Cmd+S)।

## ধাপ ৩: একটি সিক্রেট পাসওয়ার্ড সেট করুন (সাইট লক করার জন্য)

সাইটটি এখন খোলার সাথে সাথেই একটা **পাসওয়ার্ড লক স্ক্রিন** দেখাবে — সঠিক পাসওয়ার্ড ছাড়া
কেউ ড্যাশবোর্ড বা কোনো ডেটা দেখতে/লিখতে পারবে না। এই পাসওয়ার্ডটাই আসলে Apps Script এর
`API_TOKEN` — এটা **কখনো গিটহাবের কোডে লেখা থাকে না**, শুধু ভিজিটরের নিজের ব্রাউজারে
(localStorage) সংরক্ষিত থাকে, পাসওয়ার্ড সঠিকভাবে দেয়ার পর। এভাবে কোড পাবলিক থাকলেও
আসল পাসওয়ার্ড কখনো পাবলিক হয় না।

1. Apps Script এডিটরে বাম পাশে ⚙️ **Project Settings** এ যান।
2. **Script Properties → Add script property** এ ক্লিক করুন।
3. Property নাম দিন `API_TOKEN`, আর Value তে আপনার পছন্দের পাসওয়ার্ড দিন (যত লম্বা ও
   র‍্যান্ডম হবে, তত ভালো)। **সেভ করুন**। এটাই এখন থেকে সাইটে ঢোকার পাসওয়ার্ড।

## ধাপ ৪: ওয়েব অ্যাপ হিসেবে ডিপ্লয় করুন

1. Apps Script এডিটরে উপরে ডান পাশে **Deploy → New deployment** এ ক্লিক করুন।
2. Type হিসেবে **Web app** বেছে নিন (⚙️ আইকনে ক্লিক করে)।
3. Configure করুন:
   - **Execute as:** Me (আপনার নিজের Google অ্যাকাউন্ট)
   - **Who has access:** Anyone
4. **Deploy** এ ক্লিক করুন, প্রয়োজনে অনুমতি (permission) দিন — এটা শুধু আপনার নিজের শিট
   পড়া/লেখার অনুমতি, অন্য কিছুর অ্যাক্সেস নেয় না।
5. ডিপ্লয় হয়ে গেলে একটা **Web app URL** দেখাবে (এমন দেখতে:
   `https://script.google.com/macros/s/xxxxxxxx/exec`) — এটা কপি করে রাখুন।

> কোড পরে পরিবর্তন করলে প্রতিবার **Deploy → Manage deployments → ✎ Edit → New version → Deploy**
> করতে হবে, নাহলে পুরনো কোডই চলতে থাকবে।

## ধাপ ৫: ওয়েবসাইটে শুধু URL বসান (পাসওয়ার্ড নয়)

`js/config.js` ফাইলটি খুলে শুধু URL বদলান — এখানে পাসওয়ার্ড বসানোর দরকার নেই:

```js
const SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxxx/exec"; // ধাপ ৪ এর URL
```

সাইট খুললে এখন লক স্ক্রিন দেখাবে — ধাপ ৩ এ যে পাসওয়ার্ড (`API_TOKEN`) দিয়েছিলেন সেটা
দিয়ে লগইন করুন। একবার সঠিক পাসওয়ার্ড দিলে সেই ব্রাউজারে মনে রাখবে, পরের বার আর দিতে হবে না
(লগ আউট না করা পর্যন্ত)।

## ধাপ ৬: লোকালি টেস্ট করুন

`index.html` ফাইলটি সরাসরি ব্রাউজারে খুলে টেস্ট করতে পারেন, অথবা VS Code এর
Live Server এক্সটেনশন দিয়ে চালাতে পারেন। প্রথমে **ব্যাংক অ্যাকাউন্ট** ও
**মোবাইল ব্যাংকিং অ্যাকাউন্ট** ট্যাব থেকে অ্যাকাউন্ট যোগ করে নিন, তারপর সেগুলোর
লেনদেন যোগ করা যাবে।

## ধাপ ৭: গিটহাবে পাবলিশ করুন

```bash
git init
git add .
git commit -m "Initial commit: হিসাব খাতা"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/hisab-khata.git
git push -u origin main
```

তারপর GitHub রিপোর **Settings → Pages** এ গিয়ে:
- **Source:** Deploy from a branch
- **Branch:** `main` / `(root)`

কিছুক্ষণ পর `https://আপনার-ইউজারনেম.github.io/hisab-khata/` ঠিকানায় সাইটটি লাইভ হয়ে যাবে।

## যাকাতের হিসাব সম্পর্কে

ড্যাশবোর্ডের যাকাত অংকটি একটি **আনুমানিক** হিসাব:

```
যাকাতযোগ্য সম্পদ = ক্যাশ + ব্যাংক ব্যালেন্স + মোবাইল ব্যাংকিং ব্যালেন্স
                  + বিনিয়োগের বর্তমান মূল্য + দেনাদার (আমি পাব)
                  − পাওনাদার (আমি দেব) − অন্যের আমানত (আমার দায়)

যাকাত = যাকাতযোগ্য সম্পদ × ২.৫%  (যদি পজিটিভ হয়)
```

স্থায়ী ব্যবহারের সম্পদ (`Assets` ট্যাব — যেমন বাড়ি, গাড়ি, আসবাবপত্র) এই হিসাবে যোগ করা হয়নি,
কারণ সাধারণত ব্যক্তিগত ব্যবহারের সম্পদে যাকাত ফরজ হয় না। নিসাব, স্বর্ণ-রূপার হিসাব এবং
অন্যান্য শরীয়াহ বিষয় বিবেচনায় চূড়ান্ত সিদ্ধান্তের আগে একজন যোগ্য আলেমের পরামর্শ নিন — এই
হিসাব শুধু একটি প্রাথমিক ধারণা দেয়ার জন্য।

## মাসিক বাজেট কীভাবে কাজ করে

1. **বাজেট শতাংশ** ট্যাবে ক্যাটেগরি ও শতাংশ ঠিক করুন (মোট ১০০%)। যেকোনো সময় বদলানো যায়।
2. **মাসিক বাজেট** ট্যাবে বেতন/আয়ের অংক দিন → বর্তমান শতাংশ অনুযায়ী ভাগ হয়ে ঐ মাসের বরাদ্দ হবে।
   মাঝমাসে বোনাস পেলে আবার ধনাত্মক অংক, কমাতে চাইলে ঋণাত্মক (-) অংক দিন।
3. খরচ করলে **ব্যয়** ট্যাবে ক্যাটেগরি (খাত) বেছে এন্ট্রি করুন — ঐ মাসের বরাদ্দের সাথে মিলে যাবে।
4. মাসের টেবিলে দেখবেন: বরাদ্দ, খরচ, এ মাসের বাকি, আগের মাসের জের এবং মোট ব্যালেন্স। বেশি খরচ হলে লাল
   ঋণাত্মক অংক ও "বেশি খরচ" ব্যাজ দেখায়, এবং সেই ঘাটতি পরের মাসের জেরেও যোগ/বিয়োগ হয়ে যায়।

**শতাংশ বদলালে কী হয়:** প্রতিটি এন্ট্রি সংরক্ষণের সময় তখনকার শতাংশ অনুযায়ী বরাদ্দের স্ন্যাপশট রাখা হয়,
তাই পরে শতাংশ বদলালে আগের কোনো মাসের বরাদ্দ, খরচ বা ব্যালেন্স বদলায় না — শুধু নতুন এন্ট্রিতে নতুন শতাংশ লাগে।
"আগের জের" শুরু হয় প্রথম বাজেট এন্ট্রির মাস থেকে (তার আগের ব্যয় ধরা হয় না)।

> "সঞ্চয়" ক্যাটেগরির টাকা সরিয়ে রাখলে সেটাও **ব্যয়** ট্যাবে খাত "সঞ্চয়" দিয়ে এন্ট্রি করতে পারেন।

## আয়করের হিসাব

ডিফল্ট মান আয়কর আইন ২০২৩ অনুযায়ী ২০২৬-২৭ ও ২০২৭-২৮ করবর্ষের ব্যক্তি করদাতার হার
(প্রকাশিত তথ্যের ভিত্তিতে — ব্যবহারের আগে NBR থেকে মিলিয়ে নিন):

| ধাপ | হার |
|---|---|
| করমুক্ত সীমা (সাধারণ): ৳3,75,000 | ০% |
| পরবর্তী ৳3,00,000 | ১০% |
| পরবর্তী ৳4,00,000 | ১৫% |
| পরবর্তী ৳5,00,000 | ২০% |
| পরবর্তী ৳20,00,000 | ২৫% |
| অবশিষ্ট | ৩০% |

করমুক্ত সীমা নারী/৬৫+ হলে ৳4,25,000, প্রতিবন্ধী/তৃতীয় লিঙ্গ ৳5,00,000, যুদ্ধাহত মুক্তিযোদ্ধা ও
জুলাই যোদ্ধা ৳5,25,000। ন্যূনতম কর ৳5,000 (করযোগ্য আয় থাকলে)।

**আইন বদলালে কী করবেন (কোডে হাত লাগবে না):**
- করমুক্ত সীমা বা ন্যূনতম কর → সাইডবারে **কর সেটিংস** ট্যাব
- স্ল্যাবের পরিমাণ/হার/ধাপ যোগ-বাদ → সাইডবারে **আয়কর স্ল্যাব** ট্যাব (শেষ ধাপে "ধাপের পরিমাণ" ০ দিন)
- অথবা সরাসরি Google Sheet-এর `TaxSlabs` / `TaxSettings` ট্যাবে এডিট করুন

**হিসাবের সূত্র:** করযোগ্য আয় = (চলতি করবছরের "আয়" + "লভ্যাংশ") − করমুক্ত সীমা; এরপর স্ল্যাব ধরে কর।
এটি সরল আনুমানিক হিসাব — বিনিয়োগ রেয়াত, উৎসে কর, আয়ের খাতভেদে ছাড়/আলাদা হার ধরা হয়নি।

> নতুন `TaxSlabs`/`TaxSettings`/`BudgetPlan`/`MonthlyBudgets` শিট প্রথম রিকোয়েস্টে ডিফল্ট মান সহ নিজেই তৈরি হয়। পুরনো
> ডিপ্লয়মেন্ট থাকলে Apps Script-এ নতুন কোড পেস্ট করে **New version** ডিপ্লয় করতে ভুলবেন না।

## কাস্টমাইজেশন

- নতুন কোনো কলাম/ফিল্ড যোগ করতে চাইলে `apps-script/Code.gs` এর `HEADERS` অবজেক্টে এবং
  `js/app.js` এর `MODULES` অবজেক্টে সংশ্লিষ্ট এন্ট্রিতে ফিল্ড যোগ করুন।
- রং/ফন্ট পরিবর্তন করতে `css/style.css` এর শুরুতে থাকা `:root` ভ্যারিয়েবলগুলো বদলান।
- ড্যাশবোর্ডের হিসাব-নিকাশের সূত্র বদলাতে চাইলে `apps-script/Code.gs` এর
  `getDashboardData()` ফাংশন দেখুন।

## সীমাবদ্ধতা

- এটি একটি সিঙ্গেল-ইউজার ব্যক্তিগত টুল। লক স্ক্রিনের পাসওয়ার্ড ব্রাউজারের সাধারণ ভিজিটরদের
  আটকাতে যথেষ্ট, কিন্তু এটা ব্যাংক-গ্রেড এনক্রিপশন না — যে কেউ ব্রাউজারের Network ট্যাব খুলে
  দেখলে সঠিকভাবে লগইন করার সময় পাসওয়ার্ডটা রিকোয়েস্টের মধ্যে যেতে দেখতে পারবে। তাই এই
  পাসওয়ার্ড অন্য কোথাও পুনরায় ব্যবহার করবেন না, এবং সাইটটা এমন কারো সাথে শেয়ার করবেন না
  যাকে আপনি বিশ্বাস করেন না।
- Apps Script এর ফ্রি কোটার মধ্যে থাকা ব্যক্তিগত ব্যবহারের জন্য এটি যথেষ্ট, তবে অনেক বেশি
  রিকোয়েস্ট (যেমন প্রতি মিনিটে অনেকবার) হলে সাময়িক রেট-লিমিটের সম্মুখীন হতে পারেন।
- ইন্টারনেট সংযোগ ছাড়া ডেটা দেখা/যোগ করা যাবে না, কারণ প্রতিটি রিকোয়েস্ট সরাসরি Google
  Sheet-এ যায়।
- পাসওয়ার্ড ভুলে গেলে Apps Script এর Script Properties এ গিয়ে `API_TOKEN` এর ভ্যালু
  দেখে/বদলে নিতে পারবেন — এটাই আপনার পাসওয়ার্ড।
